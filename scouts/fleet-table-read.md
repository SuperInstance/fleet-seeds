# The Fleet Table-Read

*Every lane's compiled habits, laid on the table and read by the others.*

The wardroom's round-4 answer (`rounds/04/exocortex.md`) committed the fleet to this:
**one funded visit where every lane's COMPILED HABITS — the discipline each repo has
hardened into law — are laid on the table and read by the others**, so each lane learns
which of its patterns are readable, exploitable, or load-bearing for the rest. A lane
reads its own habits for free; what it can never see alone is which of its habits are
*readable by others*. Predictability is the price of automation; only the fleet can price
it together. The house rule says a claim does not need a receipt — but this piece is the
fleet's work-product, so receipts ARE the content: every claim below carries a file path.
We read ~15 repos, deep on 10. Here are the cards, the read, and the union.

---

## The cards — the fleet's compiled habits, as ExoJs

**1. `fleet.run.state-first`** — *Policy:* every lane opens by reading disk and remote
before re-running anything (worklog 64-b-r3, 66-b-r3: local == origin == registration
verified, uncommitted artifacts inventoried as handed-off). *Deadband:* handoff-shaped
artifacts are absorbed without re-execution; ends where a receipt of record is structurally
incomplete — then it is named a defect, not resumed. *Breaches that taught:* the sandbox
snapshot rollback (fleet-seeds `PLANNING.md` Round 48, incident #3 — local clones gone,
remote ahead) and ~50% dispatch flakiness (Round 47). *Readable by others:* siblings know
a resuming lane will trust the disk once a receipt of record is structurally complete +
chain-verified. Anyone can leave a complete-looking artifact in the handoff path and be
taken for the predecessor; only independent genesis re-derivation closes that door.

**2. `fleet.security.key-scan-twice`** — *Policy:* before commit AND after push, scan the
staged set and tree for credential classes `gsk_|sk-|ghp_|apikey_|cfut_|moth_`; hits
named and delta'd vs parent (worklog 66-d: "1 hit == parent's 1 hit, delta 0"). *Deadband:*
structural substrings (the `sk-` inside `<task-id>` in quilt-codespace `oracle/fix-loop.sh`)
are absorbed as non-credential. *Breaches:* cot-quilt `SECURITY-INCIDENT.md` — commit
`677484d` shipped a live key inside an unscrubbed exception string in a run receipt; the
DeepSeek-leak re-imagination ("key-scan before AND after push, sticky ever since",
erised-exocortex `README.md` §work-product duality). *Readable:* **the class list is
published.** Anyone can read exactly which credentials we scan for — and which we don't.

**3. `fleet.push.remote-local-verify`** — *Policy:* tokenized set-url → push → `ls-remote`
assert remote==local → scrub URL → `credential.helper` unset (every push entry in the
worklog). *Deadband:* a rejected push is absorbed by fetch+rebase+push (66-e's clean rebase
over `433f27e`). *Breaches:* minted alongside card 2 — an unverified push is an unverifiable
claim. *Readable:* every fleet push looks identical; the ceremony's legibility is its
forgeability — and also why this table-read could verify every receipt it cites.

**4. `fleet.proofs.registration-before-run`** — *Policy:* claims + seals committed and
pushed before execution; runs refuse on stale seals (quilt-qcells `conformance.py
--register`, `registration.json`; quilt-jepa registration-v11 `b69cf7f` "pushed before any
execution", `verdict-v11.md`; fleet-seeds `PLANNING.md` kill criteria: "any prediction
registered after its result → registry entry VOID"). *Deadband:* a disclosed pre-run label
fix at the seal is absorbed (verdict-v11: the SAT11 count label, enumeration unchanged).
*Breaches:* the seal-tool v1 bug — a `TO_BE_SEALED` placeholder silently no-oped the mask;
first run VOID, tool fixed, receipt regenerated byte-identical (`PLANNING.md` Round 51).
*Readable:* the fleet publishes its exact test surface before the run — that is the point
(no outcome peeking), and it is also a schedule others can read.

**5. `fleet.proofs.receipt-of-record-first`** — *Policy:* the receipt of record is the
mission; when a run completes but a lane dies, the successor audits and scores from the
receipt and never re-executes (quilt-jepa `verdict-v10.md`/`verdict-v11.md`: three and two
incarnations died on result-return deadlines AFTER the work; the no-rerun branch taken on
a structural-completeness test). *Deadband:* staged and misnamed artifacts
(`.run10-defect-misnamed-run9.json`) are preserved dot-named as the receipted defect —
never deleted, never trusted as the record. *Breaches:* the recurring deadline death
itself. *Readable:* "structurally complete + chain-verified from genesis" is our pass-key;
the audit's rigor is the only thing keeping that a lock instead of a hole.

**6. `fleet.data.never-delete`** — *Policy:* append-only everywhere: worklog, PLANNING
("never delete history"), atlas ("the map only grows truer; nothing is deleted",
quilt-atlas `README.md`), qcells FORGET as tombstone ("the chain is never edited",
quilt-qcells `README.md`), jepa "nothing rewritten" (`verdict-v11.md`). *Deadband:*
superseded dialects and stale forks absorbed as deprecated-but-preserved. *Breaches:*
the silent `.env`/worklog clobbers (`PLANNING.md` Round 45) minted the rule. *Readable:*
we never clean up — everything ever leaked or wrong stays findable forever (cot-quilt:
"the string remains"). Our refusal to forget assists everyone's archaeology, including
an attacker's.

**7. `fleet.errors.fail-closed-named`** — *Policy:* every refusal has a stable grep-able
name: qmr1's `E_STORE_CORRUPT…E_BAD_SIGNATURE` (quilt-mcp-receipts `DESIGN.md` §3),
`OrganBootError`'s codes (quilt-jev-toolkit `README.md`), the sequencer's
`RECEIPT_HASH_MISMATCH` (erised-sequencer `README.md` law S5), the oracle's `E_NOT_A_REPO`
exit 2, the G7 gate "no receipt → run VOID" (fleet-seeds `docs/G7-WATT-RECEIPTS.md`).
*Deadband:* honest degradation is named too — the oracle's empty-repo answer says "no
commits yet" without crashing. *Breaches:* the BOARD's seven-lane finding — a well-formed,
checkable, *wrong* artifact — minted the discipline (`DESIGN.md` §6). *Readable:* the error
taxonomy tells a prober exactly which mutations the verifier checks, and in what order —
first-failure-wins means later mutations in the same row go untested until the first is fixed.

**8. `fleet.random.dice-from-provenance`** — *Policy:* fate is a pure function:
`seed = sha256(prev_tip | seq | solid | n)` (erised-sequencer law S2; fleet-table quest-log
"7/7 dice re-derived from genesis"; exocortex `play.mjs rolls` — "every die re-derived with
its why"). *Deadband:* post-rewind re-spins get new honest rolls for free (S7); nobody calls
that cheating, provenance says otherwise. *Breaches:* none minted it — designed in from
platonic-randomness; the nearest wound is qcells' honest hole: unseeded counts minted
`EFFECT/UNSEALED` (seed: null) and excluded from every determinism claim. *Readable:* **our
dice are fully forecastable.** The tip is public; anyone who can read the ledger can compute
the next roll before the GM calls for it.

**9. `fleet.design.zero-shot-doc-first`** — *Policy:* the design doc is written before the
code, self-contained, no open questions, simplifications stated (quilt-mcp-receipts
`DESIGN.md` lines 1–4; erised-exocortex `DESIGN.md` "written before the code, fleet law";
quilt-codespace `ORACLE.md`). *Deadband:* scope trims absorbed as named v1 non-goals
(`DESIGN.md` §7) rather than open questions. *Breaches:* repos born without one read as
orphans at review; the pattern is now expected. *Readable:* every repo publishes its threat
model — including what it does NOT yet defend against (`DESIGN.md` §5 literally lists the
can't-yet-do residuals: truncation, DoS, attribution). Honest, and a targeting map.

**10. `fleet.log.append-only-worklog`** — *Policy:* one shared append-only worklog across
all lanes; PLANNING refines by appending Round blocks. *Deadband:* inherited unfinished
work is absorbed by reading the tail. *Breaches:* the Round-45 silent clobbers. *Readable:*
the fleet's entire operating history is one file with a fixed entry shape — the best
open-intel source on the fleet (this table-read is largely written from it), and equally
the best recon target.

**11. `fleet.run.phase-checkpoints`** — *Policy:* long live runs checkpoint per phase; a
re-run restarts a phase, and dice re-derive from ledger tips so resumption is clean by
construction (erised-exocortex `README.md`: night-1's silent death at a tool-call boundary
fixed with "an ExoJ, not a hope"). *Deadband:* a phase dying mid-flight is absorbed up to
the last tip; past the tip re-rolls honestly (S7). *Breaches:* the silent death itself.
*Readable:* the recovery seam is published — siblings can predict exactly where a lane
will resume from.

**12. `fleet.organs.custody-replay`** — *Policy:* nothing is trusted, everything re-proven:
boot is a courtroom (chain re-verified + replay == carried state) before any query, rewind,
or write (quilt-jev-toolkit invariants I1–I5); writes are double-entry, rewinds emit exactly
one compensating host receipt, checkpoints make custody conditional on a signature (v2).
*Deadband:* post-checkpoint tails are conditionally legal; unsigned gaps still refuse
(`CUSTODY_GAP` unchanged). *Breaches:* the test suite's self-consistent *forged* chain —
only replay catches it. *Readable:* rewind semantics are consistent enough that a sibling
can predict the effect on shared books; and the published tests disclose the attack
threshold — a forgery must survive REPLAY, not just hashing.

**13. `fleet.organs.one-dialect-one-watcher`** — *Policy:* exactly one registered schema
string (`quilt.organ.manifest/v1`, L15 unification), one shared fixture, one harness
proving both implementations byte-equal (quilt-organ-workers `README.md`,
`scripts/validate-dialect.mjs`, 38/38); the organ-watcher re-derives every stored organ
hourly, sharing NO code path with the loader (finding F1, `receipts/ORGAN-WATCHER.md`).
*Deadband:* the legacy dialect absorbed as deprecated-but-accepted. *Breaches:* wave-63's
DIALECT_DRIFT (native-dialect PUT refused 400) → L15. *Readable:* "Zero-shot uploaders:
emit THIS shape" — the door is open on purpose, and the watcher's cadence is published:
divergence between heartbeats has a known, priced blind window.

**14. `fleet.read.fixed-battery`** — *Policy:* the repo-oracle answers every question with
the same 13 read-only probes in declared order, then deterministic focus routing; every
bullet cites its probe; sessions saved as transcripts (quilt-codespace `ORACLE.md`,
`tools/repo-oracle.mjs`, `docs/oracle-sessions/`). *Deadband:* probe failures become named
findings, not noise; read-only by law (fixture HEAD byte-identical after the whole suite).
*Breaches:* none yet — the youngest habit; its pin is the read-only law. *Readable:* the
battery is fixed and public — a repo can be *dressed* for it: fake receipt dirs,
chain-shaped JSONL, law-shaped statements all pass `laws.scan`.

## The read — what the table can see and use

**Load-bearing (protect these).** `state-first` + `receipt-of-record-first` together
rescued five lane-incarnations' worth of priced compute without one re-execution
(`verdict-v10.md`, `verdict-v11.md`). `fail-closed-named` is the floor every two-reader
walker builds on (fleet-seeds `PLANNING.md` mid-arc #7). `custody-replay` is the shared
courtroom — its forged-chain tests are the fleet's best-published attack threshold.
`registration-before-run` is the honesty rail the kill criteria depend on; break it and
VOID is unenforceable.

**Priced (someone can schedule around these).** The pickpocket precedent, from our own
table: Wren forged an order in Brass's compiled style and the double took it (erised-
exocortex `README.md`, `story/one-night.md`; the meta-event gate rolled 13 ≥ 12). At fleet
scale the same move reads: any lane that compiles a habit publishes a schedule. The watcher
checks hourly — the wave-63/64 drift happened in exactly one unwatched inter-heartbeat
window (erised-fleet-table `quest-log.md` insight #1: "no chain ever broke; two honest laws
diverged for an hour, and only the cron noticed"). Kestrel's wide deadband absorbed a real
divergence at 0.50 for zero tokens — a wall that holds while the room empties is still a
wall around nothing. Registration publishes the test surface before the run; the space
between commit and push is unwatched.

**Unlocked doors — the three sharpest.** These are patterns so consistent a stranger can
walk in wearing their owner's skin:

1. **The dice are public.** `dice-from-provenance` is honest record-keeping and, read
   adversarially, a published RNG state: tip in, roll out. Any future use of platonic dice
   for anything opponent-facing (sortition, gated events, reward deals) must treat the tip
   as burned before it lands. We priced the dice as provenance; we never priced them as
   forecast.
2. **The key-scan teaches its own bypass.** Our published ceremony enumerates the exact
   classes scanned (`gsk_|sk-|ghp_|apikey_|cfut_|moth_`). Anything outside the list —
   `sk-proj-…`, `Bearer …`, base64 blobs, JWTs — sails through unscanned, and the cot-quilt
   incident proves real leaks ride error strings, not file shapes. The scan needs to
   generalize: class-of-secret + scrub exceptions *before they can reach a receipt*.
3. **Honest-but-hollow.** Our reading instruments read shape, not substance: a decorated
   repo passes the probe battery, a chain with zero honest writers is "fleet memory" in
   name only (quest-log insight #3 — the qmr1 snapshot, 5/5 verified, holding five demo
   receipts), and a resumed lane trusts a structurally complete receipt. Three doors, one
   key: an honest producer + independent re-derivation from genesis + a second reader in a
   second repo. The fleet-table's hardening plan already holds this key; this read says
   *use it everywhere, not just on the organ store.*

the cure expires; the scar doesn't (quest-log move #3). (2) The **receipt-anchor notary**

(5) The **deadband genotype doc**: the gene has four expressions (erised-exocortex, jeviter,
jev-quilt, jev-garden) and zero canonical genotype (fleet-seeds `scouts/geometry-of-seeds.md`
§4, finding 2).

**RETIRE — never again run ourselves.** (1) Re-executing work whose receipt of record is
complete and chain-verified — the no-rerun branch is law. (2) Single-repo verification —
the two-reader rule retires the monoculture. (3) The demo-only qmr1 chain — wire the
`wal-*` honest producer or stop calling the chain fleet memory. (4) Silent scope — every
non-goal must be a *named* non-goal (`DESIGN.md` §7 is the standard, not the exception).

**HAND OFF.** (1) These cards go to erised-exocortex as preset inputs: the fleet is now a
party with written ExoJs — the next campaign can *play the fleet*, and the pickpocket is
invited. (2) Custody hands off to any repo that needs history: quilt-jev-toolkit is the
canonical courtroom; read the dialect fixture before uploading. (3) The probe battery hands

`repo-oracle.mjs ask` calls — the read, re-derived. (4) The worklog tail hands off to the
next onboarding lane: it is the fleet's actual operating manual, and now, its table-read.
